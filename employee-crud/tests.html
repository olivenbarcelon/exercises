These pages contain no JavaScript, so there is no test runner to assert anything automatically. This page is the HTML-only substitute: a manual test checklist. Open each page, perform the step, compare against the expected result, and tick Pass or Fail. The checkboxes are plain <input type="checkbox"> elements — no script required.
